# SQL Project

## Introduction
This project focuses on practicing SQL fundamentals including DDL, DML, joins,
aggregations, and window functions using PostgreSQL sample data.

## Table Setup (DDL)
The database schema consists of members, facilities, and bookings tables.
Primary keys and foreign key relationships are defined to maintain data integrity.

## SQL Queries
All required SQL exercises were completed using the pgexercises dataset.
Queries include:
- INSERT, UPDATE, DELETE
- Filtering with WHERE
- JOINs and subqueries
- GROUP BY and aggregation
- Window functions

Each solution is documented and stored in `queries.sql`.

## Sample Data
The `clubdata.sql` file contains predefined sample data used to initialize
the database for query practice.

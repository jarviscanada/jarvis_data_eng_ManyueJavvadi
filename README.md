This repository contains a collection of data engineering projects.  
Each folder represents an independent project focusing on specific data engineering concepts, tools, and workflows.

## Project Structure

- [**core_java/**](./core_java)  
  Java-based system programming projects (e.g., grep implementation, Dockerization).

- [**linux_sql/**](./linux_sql)  
  Linux shell scripting and SQL fundamentals.

- [**sql/**](./sql)  
  Advanced SQL exercises, schema design, and relational modeling.

- [**python_data_analytics/**](./python_data_analytics)  
  End-to-end data analytics and wrangling project using Python, PostgreSQL, and Jupyter Notebook.  
  Includes data exploration, customer analytics, and RFM segmentation.

## Technologies Used

- Java, Python, SQL  
- PostgreSQL  
- Docker  
- Jupyter Notebook  
- Git & GitHub

Each project folder contains its own README with detailed explanations.
